# character-refs

**สร้างภาพอ้างอิงตัวละครให้จริง** จากเรื่องราวใด ๆ — นิยายดัดแปลง เรื่องที่แต่งเอง หรือตัวละครเดี่ยว โดยไม่ต้องมีบทเล่าเรื่อง อธิบายตัวละครในข้อความเดียว แล้วได้ชุดภาพอ้างอิงที่แนบเข้าโมเดลวิดีโอ (H3 / Wan / Seedance) ต่อได้ทันที

**ชุดภาพหนึ่งชุดมีรากเดียว**: ภาพเต็มตัวด้านหน้า (ภาพหลัก) เป็นภาพเดียวที่ใช้ text-to-image ส่วนภาพหน้าตรง โปรไฟล์ ด้านหลัง และภาพรายละเอียด อ้างอิงภาพหลักเท่านั้น ไม่อ้างอิงกันเอง — ภาพใดเสียให้สร้างใหม่เฉพาะภาพนั้น ไม่เกี่ยวโยงภาพอื่น

## ภาษา

- `lang` กำหนดภาษาของตารางยืนยันและหน้ารายงาน: `zh`, `th`, `en`, `ja` มีมาให้ในตัว ภาษาอื่นแปลสดขณะใช้งาน
- `contentLang` กำหนดภาษาของเนื้อหาตัวละคร: ค่าเริ่มต้น `zh` รองรับ `th`, `en`, `ja` — ช่องที่ให้คนอ่านต้องเขียนด้วยภาษาตาม `contentLang`
- พรอมต์ภาพเป็นภาษาอังกฤษเสมอ และห้ามมีชื่อตัวละคร
- การนับความยาวภาษาไทยไม่นับสระและวรรณยุกต์แบบ combining

## ระดับภาพ

| ระดับ | เนื้อหา | ใช้เมื่อ |
| --- | --- | --- |
| 1 | เต็มตัวด้านหน้า (ภาพหลัก) | ทุกครั้ง เป็นภาพแรก |
| 2 (ค่าเริ่มต้น) | ภาพหน้าตรง โปรไฟล์ 90° ด้านหลัง | สร้างเป็นค่าเริ่มต้น |
| 3 | รายละเอียดที่ผู้ใช้ระบุ หรือจุดเด่นที่จำได้ง่ายที่สุด ถ้าไม่ระบุจะใช้ผม/เครื่องประดับผม คอเสื้อ ปลายแขน รองเท้า | ภาพระยะใกล้ของเครื่องประดับหรือรายละเอียดเสื้อผ้า |
| 4 (ปิดอยู่) | ภาพหน้าตรงมุม 45° | เมื่อร้องขอ |

## การป้อนข้อมูลครั้งเดียว

ไม่มีฟอร์มให้กรอก อธิบายตัวละครในข้อความเดียวพอ — agent แยกเป็นช่องตัวตน ใบหน้า ผม รูปร่าง ผิว เสื้อ กางเกง รายละเอียด เติมช่องที่ขาดให้ ติดป้ายที่มาของแต่ละช่อง (ผู้ใช้ระบุ / อนุมาน / ค่าเริ่มต้น) แล้วพิมพ์ตารางยืนยันให้ดู จะถามเพิ่มเฉพาะเมื่ออายุ เพศ หรือยุคสมัยอนุมานไม่ได้

ตัวอย่างภาษาไทย: `examples/มะลิ-intake.json` — หญิงขายดอกไม้กรุงเทพฯ ทศวรรษ 1960 ใช้ตรวจตารางยืนยันและหน้ารายงานภาษาไทยโดยไม่เรียกโมเดล:

```bash
node scripts/character-refs.mjs intake-check examples/มะลิ-intake.json
node scripts/character-refs.mjs new examples/มะลิ-intake.json --out /tmp/refs/
```

## โมเดล

สี่แบบ เลือกครั้งแรกที่ใช้แล้วใช้ต่อเรื่อย ๆ:

| โมเดล | คำอธิบาย |
| --- | --- |
| `qwen` | Qwen Image 2.1 ผ่าน ComfyUI ของตัวเอง ได้ขนาดภาพตรงตามสั่ง ไม่ใช้โควตาแบบสมัครสมาชิก |
| `codex` | โมเดลสร้างภาพในตัวของ codex ไม่ต้องใช้ API key แต่ใช้โควตาแพลน ChatGPT |
| `openai` | OpenAI Images API ค่าเริ่มต้น gpt-image-2 จ่ายตามการใช้งาน |
| `custom:<name>` | คำสั่งสร้างภาพของตัวเอง เติม `{prompt_file}` `{refs}` `{out}` `{width}` `{height}` ลงในเทมเพลต |

ภาพหลักและภาพที่ได้มาใช้โมเดลต่างกันได้ ความสม่ำเสมอมาจากการใช้ภาพหลักภาพเดียวร่วมกัน ไม่ใช่จากการใช้โมเดลเดียวกัน

## เกณฑ์ตรวจภาพ

`check` ตรวจด้วยโค้ดและจบด้วย exit 1 เมื่อไม่ผ่าน: ความยาวด้าน 300–5760 พิกเซล สัดส่วนกว้างยาว 0.4–2.5 สัดส่วนภาพตรงตามชนิดมุมมอง (2:3 / 4:5 / 1:1) ไฟล์ไม่เกิน 20 MB พื้นหลังขาวตามชนิดมุมมอง (ภาพเต็มตัวตรวจสี่ด้าน ภาพหน้าตรงตรวจด้านบนและสองข้างช่วงบน ภาพรายละเอียดข้ามและระบุไว้ชัดเจน) และสถานะต้องสร้างใหม่ **เกณฑ์เหล่านี้ตัดสินความเหมือน มุมกล้อง และการวางองค์ประกอบไม่ได้** ส่วนนั้นต้องตรวจด้วยสายตา

## คำสั่งหลัก

```bash
node scripts/character-refs.mjs config --model qwen --confirm-anchor yes --qwen-env-file ~/comfy.env
node scripts/character-refs.mjs intake-check examples/มะลิ-intake.json
node scripts/character-refs.mjs new examples/มะลิ-intake.json --out out/
node scripts/character-refs.mjs gen out/มะลิ/asset.json          # ภาพหลัก แล้วหยุดรอการยืนยัน
node scripts/character-refs.mjs confirm out/มะลิ/asset.json
node scripts/character-refs.mjs gen out/มะลิ/asset.json          # เติมระดับ 2: หน้าตรง โปรไฟล์ ด้านหลัง
node scripts/character-refs.mjs check out/มะลิ/asset.json
node scripts/character-refs.mjs render out/มะลิ/asset.json --lang th --out out/character-refs.html
```
