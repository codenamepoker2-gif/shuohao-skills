# novel-script

เขียนบทละครสั้นสำหรับผลิตด้วย AI: เปลี่ยนเรื่องย่อรายตอนจาก novel-outline ให้เป็นฉากและบทพูด วางไว้บนข้อตั้งที่ว่า **บทละครดูแลเรื่องความเป็นละคร สตอรีบอร์ดดูแลเรื่องการถ่ายทอด** ชั้นนี้จึงไม่มีเลขช็อตและไม่มีพรอมต์ภาพ นั่นเป็นงานของ novel-storyboard ชั้นถัดไป

แนวคิดหลักคือ **บทพูดเป็นข้อมูลมีโครงสร้าง ไม่ใช่ร้อยกรอง**:

- **ลำดับจังหวะ**: แต่ละฉากสลับระหว่างจังหวะแอ็กชันกับบรรทัดบทพูด ทุกบรรทัดระบุผู้พูดและน้ำเสียง ใช้สร้างเสียงพากย์รายบรรทัดได้ทันที
- **งบเวลารายตอน**: บทพูดถูกแปลงเป็นเวลาตามอัตราการอ่าน ภาษาไทยเริ่มที่ 13 ตัวอักษรพื้นฐาน/วินาที (ไม่นับสระและวรรณยุกต์แบบ combining) ภาษาจีนคงที่ 4.5 ตัวอักษร/วินาที แต่ละตอนต้องอยู่ในช่วงเป้าหมาย ±15%
- **ฮุคเปิดเรื่อง + ปมชวนติดตาม**: ต้องมีในทุกตอน และ **ฮุคต้องเป็นจังหวะแรก ๆ ของตอน ไม่ใช่แค่ป้ายชื่อ** — `hookBeat` ต้องมาภายใน 3 จังหวะแรกของตอน
- **เสียงบรรยาย**: ใช้เครื่องหมาย `VO` กับเสียงในใจและเสียงบรรยาย และจัดกลุ่มแยกในสารบบบทพูด

ผลลัพธ์คือ `script.json` บทละคร Markdown และ `script-report.html` แบบไฟล์เดียว

## ภาษา

- `lang` กำหนดภาษาของหน้ารายงาน: `zh`, `th`, `en` มีมาให้ในตัว ลำดับความสำคัญคือ `--lang` > ฟิลด์ `lang` ใน JSON > ค่าเริ่มต้น `zh`
- `contentLang` กำหนดภาษาของบท: ค่าเริ่มต้น `zh` รองรับ `th` และ `en` — ควบคุมการนับความยาวบทพูดและการคำนวณเวลา
- การเปลี่ยนภาษาหน้ารายงานไม่แปลบทพูดให้เอง

ตัวอย่างการใช้งาน:

```bash
node scripts/novel-script.mjs render examples/渡口-script.json --html --lang th > /tmp/script-th.html
node scripts/novel-script.mjs render examples/渡口-script.json --html --lang en > /tmp/script-en.html
```

## ด่านคุณภาพเป็นโค้ด

ด่านคุณภาพทั้ง 10 ด่านตรวจแบบกำหนดผลได้ใน `validate`: ความยาวเวลาแต่ละตอนอยู่ในช่วง ±15% ความยาวบทพูดต่อบรรทัด ความถูกต้องของผู้พูด ฮุคและปมชวนติดตามบนกระดาษ ฮุคต้องเกิดใน 3 จังหวะแรก แต่ละฉากต้องมีจังหวะแอ็กชันอย่างน้อยหนึ่งจังหวะ แอ็กชันต้องเป็นร้อยแก้วไม่มีบทพูด จุดพีคที่โครงเรื่องสัญญาไว้ต้องมีฉากรองรับ และการอ้างอิงตัวละครกับฉาก

## ขั้นตอนทำงาน

1. มี `outline.json` ให้ใช้ `seed --eps 1-3` เติมโครงของแต่ละตอนแบบกำหนดผลได้
2. เขียนฉากและบทพูดทีละไม่เกิน 3 ตอน — บทละครคือชั้นที่ถูกแก้บ่อยที่สุดในไปป์ไลน์
3. ใช้ `validate --outline --art` ตรวจกับโครงเรื่องและงานศิลป์จนผ่านทุกด่าน
4. ใช้ `render --lang th` ออกรายงานภาษาไทย

คำสั่งหลัก:

```bash
node scripts/novel-script.mjs seed outline.json --eps 1-3
node scripts/novel-script.mjs validate script.json --outline outline.json --art art.json
node scripts/novel-script.mjs checkup script.json
node scripts/novel-script.mjs render script.json --html --lang th > script-report.html
node scripts/selftest.mjs
```

ตัวอย่าง `examples/渡口-script.json` คือบทฉบับเต็ม 6 ตอนที่ผ่านทุกด่านคุณภาพ ใช้ทดสอบรายงานสามภาษาและการคำนวณเวลาโดยไม่เรียกโมเดล
