# shuohao-skills — เครื่องมือผลิตละครสั้นด้วย AI

ชุด skill สำหรับเปลี่ยนนิยายเป็นโครงเรื่อง ตัวละคร งานศิลป์ บทละคร และสตอรีบอร์ด ใช้กับ Claude Code หรือ Codex ได้ แต่ละ skill ทำงานได้ในตัวและคัดลอกไปใช้งานแยกได้ โดยไม่ต้องติดตั้ง skill อื่นหรือแพ็กเกจ npm

## ขั้นตอนการทำงาน

เริ่มจากตกลงเรื่องและโครงสร้าง ก่อนออกแบบช็อตหรือสร้างภาพ จากนั้นพัฒนาบทละคร ตัวละคร และงานศิลป์ควบคู่กัน สตอรีบอร์ดถ่ายทอดสิ่งที่ตกลงไว้แล้ว ไม่เพิ่มการตัดสินใจด้านเรื่องใหม่

| Skill | หน้าที่ |
| --- | --- |
| [novel-outline](skills/novel-outline/README.th.md) | ดัดแปลงนิยายเป็นโครงเรื่อง รายชื่อตัวละคร จุดสำคัญของเรื่อง เรื่องย่อรายตอน และรายการทรัพยากร |
| [novel-characters](skills/novel-characters/README.th.md) | จัดทำประวัติ รูปลักษณ์ เสียง และภาพออกแบบตัวละคร |
| [novel-art](skills/novel-art/README.th.md) | ออกแบบฉากและอุปกรณ์ประกอบฉาก พร้อมรายละเอียดที่ต้องคงที่ |
| [novel-script](skills/novel-script/README.th.md) | เขียนฉาก จังหวะเรื่อง และบทพูด พร้อมคำนวณเวลาและรวมบทพูดตามตัวละคร |
| [novel-storyboard](skills/novel-storyboard/README.th.md) | แบ่งบทเป็นช่วงภาพ ช็อต และภาพหลัก พร้อมส่งออกชุดข้อมูลสำหรับผลิตวิดีโอ |
| [character-refs](skills/character-refs/README.th.md) | สร้างภาพอ้างอิงตัวละคร โดยใช้ภาพเต็มตัวด้านหน้าเป็นหลักสำหรับมุมอื่น |

## ติดตั้ง

ต้องมี Node.js 18 ขึ้นไป สคริปต์ใช้เฉพาะไลบรารีมาตรฐาน การทดสอบไม่เรียกโมเดลและไม่ใช้โควตา

จากโฟลเดอร์ของ fork นี้:

```bash
./scripts/install.sh
./scripts/install.sh --codex
./scripts/install.sh novel-characters
```

ตัวติดตั้งสร้าง symbolic link จึงใช้การแก้ไขในคลังนี้ได้ทันที ถอนการเชื่อมโยงด้วย `./scripts/install.sh --uninstall` ดูการตั้งค่าผู้ให้บริการภาพใน README ของ skill ที่ต้องสร้างภาพ

## ภาษา UI และภาษาเนื้อหา

ทั้งหก skill รองรับ UI ไทย อังกฤษ และจีน เลือกด้วย `--lang th` หรือ `--lang en` ลำดับความสำคัญคือ **ตัวเลือก `--lang` > ฟิลด์ `lang` ใน JSON > ค่าเริ่มต้น `zh`** ส่วน character-refs ยังคงรองรับภาษาญี่ปุ่นและพจนานุกรม UI กำหนดเอง

ภาษาเนื้อหาแยกจากภาษา UI ให้ตั้งค่าที่รากของ JSON:

```json
{
  "lang": "th",
  "contentLang": "th"
}
```

`contentLang` เลือกได้ `zh`, `th`, `en` หากไม่ระบุจะใช้กฎภาษาจีนเดิม การเปลี่ยน UI ไม่แปลชื่อเรื่องหรือบทพูดให้เอง ช่อง prompt สำหรับโมเดลภาพและวิดีโอยังคงต้องเป็นภาษาอังกฤษ รวมถึงวลีบังคับของโมเดล

สำหรับสตอรีบอร์ดที่ระบุ `contentLang: "th"` หรือ `"en"` ทุกช็อตต้องมี `shotPrompt` ภาษาอังกฤษสำหรับ Seedance และ `frame` ภาษาอังกฤษสำหรับสร้างภาพ ส่วน `shot` เป็นคำบรรยายภาษาของเรื่อง ไม่ใส่บทพูดในช่องเหล่านี้ เพราะตัวส่งออกจะเติมบทพูดต้นฉบับในเครื่องหมายบทพูดให้ ดูข้อกำหนดองค์ประกอบภาพสำหรับโมเดลใน [schema ของ storyboard](skills/novel-storyboard/references/schema.md)

การนับความยาวภาษาไทยไม่นับเครื่องหมายผสม เช่น สระบน/ล่างและวรรณยุกต์ อัตราบทพูดไทยเริ่มต้นที่ **13 ตัวอักษรต่อวินาที** เป็นค่าตั้งต้นสำหรับวัดและปรับกับนักพากย์หรือเสียง TTS จริง ภาษาจีนคงค่าเดิม 4.5 ตัวอักษรต่อวินาที ดูรายละเอียดข้อกำหนดและตัวเลือกปรับเวลาในเอกสารของแต่ละ skill

## สร้างรายงาน

ตัวอย่างรายงานโครงเรื่องจากข้อมูลตัวอย่างของ skill นั้นเอง:

```bash
node skills/novel-outline/scripts/novel-outline.mjs render \
  skills/novel-outline/examples/渡口-outline.json --html --lang th > /tmp/outline-report.html
```

รวมรายงานที่มีอยู่เป็นหน้าเดียว:

```bash
node scripts/report.mjs --from <โฟลเดอร์งาน> --lang th --out /tmp/production-report.html
```

จัดไฟล์งานไว้ใน `outline/`, `characters/`, `art/`, `script/`, `storyboard/` ภายในโฟลเดอร์งาน ตัวรวมรายงานเลือกเฉพาะขั้นตอนที่มีข้อมูล หรือระบุไฟล์ตรงด้วย `--outline`, `--cast`, `--art`, `--script`, `--storyboard` ได้ สตอรีบอร์ดต้องมีบทละครประกอบ

ตัวรวมใช้ภาษาใน JSON ขั้นตอนแรกเมื่อไม่ระบุ `--lang` แล้วส่งภาษานั้นไปยังทุกส่วน ปุ่ม “แสดงทั้งหมด” เปิดทุกส่วนเพื่อค้นหาด้วย Cmd+F ปุ่มตัวเลข 1–5 ใช้สลับส่วน

ภาพของสตอรีบอร์ดต้องอยู่ตามเส้นทางที่รายงานอ้างอิง เก็บโฟลเดอร์ช่วงภาพไว้ระดับเดียวกับรายงาน หรือระบุตำแหน่งผ่านตัวเลือกของ skill ห้ามนำ HTML ที่สร้างใหม่ได้ เช่น `gallery.html` และ `*-report.html` เข้า version control
